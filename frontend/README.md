# MODERN Furniture Steel 🛋️✨

منصة تجارة إلكترونية متكاملة (Full Stack MERN) مخصصة لمصنع أثاث معدني في مصر. يهدف النظام إلى عرض المنتجات بتصنيفات مختلفة، السماح للعملاء بطلب المنتجات، وتمكين الإدارة من التحكم في المحتوى والطلبات.

## 🚀 نبذة عن المشروع

تم بناء هذا المشروع كمشروع تخرج يحاكي بيئة عمل حقيقية، حيث يمكن للمستخدمين تصفح الكتالوج، قراءة وإضافة التقييمات، إتمام الطلبات، ومتابعة حالتها. في المقابل، يمتلك المدير لوحة تحكم كاملة لإدارة المخزون وتحديث حالات الطلبات.

## 🛠️ التقنيات المستخدمة (Tech Stack)

### الواجهة الأمامية (Frontend)
* **React.js (v19) & JavaScript (JSX):** لبناء واجهة مستخدم تفاعلية وسريعة (Single Page Application).
* **Vite:** أداة بناء سريعة جداً للمشروع.
* **React Router DOM:** لإدارة التوجيه والتنقل بين الصفحات.
* **Context API:** لإدارة الحالة العالمية (السلة، المستخدم، المنتجات).
* **Tailwind CSS:** لتنسيق الموقع بشكل عصري ومتجاوب (Responsive).
* **Axios:** للتعامل مع طلبات الـ API.
* **Lucide React:** للأيقونات العصرية.

### الواجهة الخلفية (Backend)
* **Node.js & Express:** بيئة السيرفر وبناء الـ RESTful API.
* **MongoDB & Mongoose:** قاعدة بيانات NoSQL لتخزين المنتجات، المستخدمين، والطلبات.
* **JWT (JSON Web Tokens):** لتأمين المصادقة وإدارة الجلسات.
* **Bcryptjs:** لتشفير كلمات المرور لحماية بيانات المستخدمين.
* **Multer:** لرفع الصور وتخزينها على السيرفر.

## ⭐ المميزات الرئيسية

### 👤 للمستخدمين (العملاء):
1.  **تصفح ذكي:** عرض المنتجات حسب الأقسام مع تفاصيل دقيقة للأسعار والصور.
2.  **عربة التسوق (Cart):** سلة ديناميكية تُحفظ في المتصفح.
3.  **نظام التقييمات:** إمكانية تقييم المنتجات بالنجوم وكتابة آراء تظهر لباقي العملاء (للمسجلين فقط).
4.  **تتبع الطلبات:** لوحة خاصة بالعميل لمتابعة طلباته السابقة ومعرفة حالة الطلب (قيد المراجعة، تم التسليم...).

### 🛡️ للمدير (Admin):
1.  **لوحة التحكم (Dashboard):** واجهة خاصة محمية للإدارة.
2.  **إدارة المنتجات:** إضافة منتجات جديدة مع رفع الصور، وحذف المنتجات.
3.  **إدارة الطلبات:** رؤية تفاصيل الطلبات، بيانات الشحن، وتحديث حالة الطلب وإرسال ملاحظات للعميل.
4.  **إدارة التقييمات:** صلاحية حذف التقييمات غير اللائقة.

اتبع الخطوات التالية لتشغيل المشروع محلياً على جهازك:

### 1. إعداد السيرفر (Backend)
افتح التيرمينال وانتقل لمجلد الباك إند:

npm install
npm run dev

2. إعداد الواجهة (Frontend)
